# Raw generated clips (Veo 3.1 Lite, 720×1280, native audio)
- `v1/`: the clips cut into V1, named by script shot number.
- `v3/`: the clips cut into the current V3 (Hook 1 rework + locked couch coverage).
Clips are untrimmed. Trims, crops and overlays are applied by `../edit/assemble_v3.py`.
`_UNCROPPED` marks clips that are edge-cropped in the edit to remove a stray second person (04: face crop, 16: left 14%, 17: right 14%).
Higgsfield job IDs for every clip are in `../clip_prompts_main.md`.
