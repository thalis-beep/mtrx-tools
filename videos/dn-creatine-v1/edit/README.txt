DN CREATINE · MTRX_DNCR5_AI_SA_OBANM2 · V1 (Bloating) · Premiere package
========================================================================

Sequence: 1080x1920 · 24 fps · 75.83 s · stereo 48 kHz

OPEN IN PREMIERE
1. Unzip anywhere. Keep the folder structure as it is.
2. Premiere: File > Import > DNCR5_V1_Premiere.xml
3. Media will show as offline (the XML points to /DNCR5_V1_Premiere/...).
   Right-click any clip > Link Media > Locate the matching file once
   (e.g. video/S01.mp4) with "Relink others automatically" ticked: everything relinks.

EDITABLE CAPTIONS (instead of PNGs)
captions.srt has the same 76 captions with the same timing.
File > Import > captions.srt > drag onto the timeline > style in Essential Graphics
(Anton, all caps, white fill, black stroke). To turn them into text layers: select the caption
track items > right-click > "Upgrade Caption to Graphic". Then disable V7.
Font: fonts/Anton-Regular.ttf (SIL Open Font License, free for commercial use) — install it first.

RAW CLIPS
raw/ has the full-length 5 s generated clips if you want to re-trim with handles.

NOTES

  lay the real packshot over it.
