# Script Analysis

Analyse the script before any creative decision. The goal is a **beat map**: every
piece of audio paired with the visual it requires.

## Intake checklist

| Item | Blocks production? | If missing |
|---|---|---|
| Script text (VO / dialogue / lyrics) | Yes | Ask |
| Product reference images (front + any other visible sides, logo close-up) | Yes, when a product appears | Ask. Never invent packaging |
| Animation style direction or reference | Usually | Propose 2 style options from the brief and ask |
| Final audio file | No, but timing is estimated until it arrives | Estimate (see below) and mark every timestamp `EST` |
| Character descriptions | No | Design from the brief, then get approval at Gate 1 |
| Target length, format, platform | No | 9:16, length = audio length (or about 2.5 spoken words per second) |
| Credit balance and budget cap | No, if the balance tool works | Read the balance, otherwise ask |
| Plan B target tools | Only for Plan B | Ask which image and video tools the editor will use |
| Mandatory claims, legal lines, end card | No | Check with the CS whether a disclaimer or end card is needed |
| Captions / on-screen text needed? | No | Assume captions are added in the edit, not generated in-image |

Put every question in **one message**. Record each unanswered non-blocker as an
assumption in the bible.

## Analysis steps

1. **Concept and audience**: the one-sentence idea, who it's for, and the feeling the
   viewer should leave with.
2. **Style**: the medium (2D, 3D, claymation, stop-motion, pixel, CGI…), reference
   titles or images, palette, line or texture treatment. Adopt the CS's direction and
   don't impose a house look.
3. **Cast**: each character's role, how often they appear, any variants
   (before/after, outfits), and their relationship to the product.
4. **Products**: each SKU that appears, where it must be visible, and any hero moment.
5. **Structure and arc**: hook (first 1–3 s), problem, turn, solution or product,
   payoff, CTA. Note the emotion at each stage.
6. **Beat map**: split the audio into beats. A beat is one idea, usually one VO phrase,
   one lyric line, or one musical phrase.
7. **Literal obligations**: underline every concrete thing the script names, such as
   an action ("she slams the laptop shut"), an emotion ("relieved"), an object ("the
   red bottle"), or a transformation ("the dull room bursts into colour"). Each one
   needs a shot that clearly delivers it.
8. **Pacing**: use the CS's timestamps when given. Otherwise estimate.

## Estimating timing without final audio

- Spoken VO: about **2.5 words/second** for energetic ad reads, about 2.0 for calm.
- Lyrics: use the tempo if known (60 / BPM × beats per line). Otherwise one lyric
  line ≈ 2–4 s.
- Mark estimated timestamps `EST`. When the real audio arrives, retime
  (`audio-sync-editing.md` § Retiming).

## Beat map format

| Beat | Time | Audio (verbatim) | Literal obligations | Emotion | Visual idea |
|---|---|---|---|---|---|
| B1 | 0.0–2.0 EST | "Tired of flat hair?" | flat hair, tired | frustrated | CU: character pulls limp strand, sighs |

Beats become scenes. One beat can need 1–2 shots, and two short beats can share one
shot. Decide this in the storyboard.

## Red flags to raise before production

- A line no reliable AI shot can show (complex hand-object interaction, readable
  small text, multiple characters touching). Propose a simpler staging.
- A product moment that depends on exact label legibility. Plan a composite or a
  real-packshot insert.
- The script length doesn't match the target duration.
- Style references that conflict with each other.
- Real people, celebrities or copyrighted characters. Use original designs only.
